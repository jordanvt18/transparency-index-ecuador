Metodología

Definición del Índice

El Índice de Transparencia Municipal es una medida compuesta (0–100) que evalúa cuatro dimensiones clave de la transparencia en gobiernos locales del Ecuador.

1. Apertura de Datos (30%)

  • Disponibilidad de portal de transparencia (30 pts)
  • Formatos abiertos de datos (25 pts)
  • API pública disponible (25 pts)
  • Datos actualizados (20 pts)

2. Compras Públicas (30%)

  • % de contratos por licitación pública vs adjudicación directa (40 pts)
  • % de contratación directa — menor es mejor (30 pts)
  • Concentración de proveedores (HHI) — menor concentración es mejor (30 pts)

3. Rendición y Auditoría (20%)

  • % de informes de auditoría publicados (40 pts)
  • % de recomendaciones de auditoría cumplidas (40 pts)
  • Ausencia de sanciones (20 pts)

4. Declaraciones Patrimoniales (20%)

  • % de autoridades con declaración pública (60 pts)
  • Tiempo de publicación — más rápido es mejor (40 pts)

Matching de Municipios Similares

Para comparar municipios "parecidos", se utiliza el algoritmo k-nearest neighbors (KNN) sobre un espacio normalizado de features socioeconómicas: población, PIB per cápita, presupuesto municipal, densidad urbana, tasa de pobreza e IDH cantonal.

Fuentes de Datos

  • SERCOP — Servicio Nacional de Contratación Pública (contratos y licitaciones)
  • Contraloría General del Estado — Informes de auditoría y sanciones
  • INEC — Indicadores socioeconómicos
  • Portales de transparencia municipal — Declaraciones patrimoniales

Consideraciones Éticas y Legales

  • Los datos personales sensibles son anonimizados.
  • No se publican acusaciones; se enlaza a documentos oficiales.
  • Los vacíos de datos se documentan; no se imputan sin evidencia.
  • Se incluye disclaimer y guía para periodistas/ciudadanos sobre interpretación.

Reproducibilidad

El pipeline completo es reproducible: scripts/ingest_procurement.py → src/etl/compute_metrics.py → src/compute_transparency_index.py → src/compute_similar_municipios.py. Los pesos son ajustables desde la UI.
